# Agent Notes

This directory keeps concise guidance for agents working on OpenScene documentation and code. Read the root `AGENTS.md` first, then use these notes for focused tasks.

Files:

- `rebrand.md`: product naming and compatibility rules.
- `compatibility.md`: identifiers that must not change.
- `tests.md`: verification commands and manual QA surfaces.
- `docs.md`: documentation style and scope notes.

Keep these files short. They are guidance, not a second README.
