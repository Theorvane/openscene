# Support

## Getting Help

For installation, usage, and local FFmpeg setup, start with the [README](README.md). OpenScene is an MVP local-first Electron app; supported behavior and current limitations are documented there.

For reproducible bugs or feature ideas, use the GitHub issue forms. Before filing, search existing issues and include only the information needed to reproduce the problem.

## Keep Public Reports Safe

Do not post recordings, voice samples, credentials, tokens, private file paths, or other sensitive material in public issues. For potential security problems, follow [SECURITY.md](SECURITY.md); no private vulnerability-reporting channel is currently configured.

## What Maintainers Can Help With

Maintainers can triage reproducible issues in the current OpenScene codebase and discuss scoped contributions. They cannot provide support for private media recovery, third-party FFmpeg builds, local model/runtime setup, operating-system permissions, or custom hardware environments beyond the documented guidance.
